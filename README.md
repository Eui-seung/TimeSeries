1. 전처리 끝내기

개선할 점 정리

날씨 종류(폭우/폭설/한파 등) × 역 유형(환승역/주거지역/업무지구 등) 표를 만들어 각 칸의 사용 가능한 사건 수를 적어 넣기

사건이 너무 적은 칸은 합치거나("제외" 또는 "참고용"으로 표시)

역 분류 기준을 명확히 설명하기 (예: 승하차 패턴, 주변 지역 특성 등으로 어떻게 나눴는지)

기준선과 회복의 정의를 명확히 + 정보 누수 점검

**중요** 실제 날씨 강도 구분
