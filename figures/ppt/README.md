# figures/ppt/ — 발표용 그림

`notebooks/06_figures_ppt.ipynb`를 위에서 아래로 실행하면 12개 그림이 모두 다시 만들어집니다 (PNG, 가로 10인치, 300dpi = 3000픽셀, 높이 1680픽셀 / 8번만 1980픽셀).

**공통 규칙**: 제목·축·범례는 영어, 역 이름만 한글(AppleGothic). 역 유형 색은 고정입니다 — Employment 파랑(#2a78d6), Commercial & Leisure 초록(#1baf7a), Residential 주황(#eb6834). 변화율은 %이고 0에는 점선입니다. 글꼴이 없는 컴퓨터(macOS가 아님)에서는 한글 역 이름이 깨질 수 있습니다.

**그림 묶음과 슬라이드 순서(제안)**: 데이터·방법(01~03) → SARIMAX(04~07) → 이벤트 분석(08~10) → 모형 비교(11~12)
